# TRADE//OS 数据与供应商地图

状态：阶段 0 草案；收费前需要法律与安全专业复核  
版本：2026-07-28

## 1. 数据流总览

### CSV / 手动记录

`用户浏览器`

→ `Vercel 上的 TRADE//OS API`

→ `CSV 解析与字段映射`

→ `用户预览/确认`

→ `libSQL 数据库（生产环境预计为 Turso）`

### 截图识别

`用户明确选择图片并提交`

→ `Vercel API 在内存中读取图片`

→ `图片以 inline base64 发送到 Google Gemini API`

→ `Gemini 返回结构化候选字段`

→ `TRADE//OS 校验字段`

→ `用户预览、修改和确认`

→ `确认后的交易保存到数据库`

当前 POST 路径未观察到原始图片持久化；若请求携带 `screenshotUrl`，PUT 路径可以把 URL 和 extractedFields 保存到 `trade_screenshot`。截图 URL 从哪里生成、由谁托管、保存多久，目前没有形成可信闭环。

## 2. 当前供应商

| 供应商/组件 | 当前用途 | 发送/保存的数据 | 当前状态 | 阻断问题 |
|---|---|---|---|---|
| Vercel | Web 托管、Server Functions、运行日志 | 请求、账户/交易 API 数据、运行元数据 | 已使用 | 日志保留、区域、访问控制和费用告警未成文 |
| Turso / libSQL | 用户、账户、交易和设置数据库 | 邮箱、交易账户、交易记录、映射、设置 | 代码支持；本地无 env 时退回 SQLite 文件 | 备份、恢复、区域、DPA、生产连接是否一致未验收 |
| Google Gemini API | 用户主动上传图片后的字段提取 | 原始上传图片及提取提示 | 已在代码使用 `gemini-3.1-flash-lite` | 隐私页仍写 DeepSeek；供应商披露错误 |
| NextAuth Credentials | 登录与会话 | 邮箱、用户 ID、JWT 会话 | 当前为开发预览 | 任意邮箱可直接创建并登录；收费/外测前必须替换 |
| 浏览器 localStorage | 语言偏好 | locale | 已使用 | 必须与服务器设置同步规则一致 |
| DeepSeek | 隐私页宣称的图片供应商 | 隐私页声称会发送截图 | 实际截图代码未使用 | 必须从隐私页删除或说明真实用途 |

未来但尚未批准：

- Stripe：付费封闭 Beta 才接入。
- 邮件供应商：生产登录和通知需要选择。
- 错误监控供应商：公开测试前选择。
- 图片对象存储：只有确认必须保留证据图时才选择。

## 3. 数据类别

| 数据类别 | 示例 | 敏感度 | 默认用途 | 推荐保存策略 |
|---|---|---:|---|---|
| 身份数据 | 邮箱、显示名 | 高 | 登录、支持 | 账户有效期间；删除请求后按政策清理 |
| 会话数据 | JWT、session token | 高 | 登录状态 | 最短必要期限 |
| 交易账户设置 | 券商标签、币种、余额、时区 | 高 | 计算和显示 | 账户有效期间 |
| 交易记录 | 标的、时间、价格、P&L、费用 | 高 | 日志和分析 | 用户控制；支持导出和删除 |
| 原始 CSV | 券商导出文件 | 高 | 临时解析 | 默认不长期保存；解析完成后丢弃 |
| 原始截图 | 交易截图、可能含账号/余额 | 高 | 用户主动视觉提取 | 默认仅处理，不持久化；保留必须单独同意 |
| 提取候选 | Gemini 读出的字段和置信度 | 中高 | 用户确认 | 未确认候选短期保留或仅存在浏览器会话 |
| 用户确认交易 | 用户修正后的字段 | 高 | 正式分析 | 存入交易数据库 |
| AI 洞察 | 解释、证据链接、置信状态 | 中高 | 复盘 | 未来需定义版本和删除关系 |
| 产品日志 | 错误、耗时、用量 | 中高 | 运维、成本 | 不记录图片、API Key、完整交易或邮箱 |
| 支付数据 | 套餐、付款状态 | 高 | 订阅 | 由支付供应商托管；本地只存必要标识 |

## 4. 数据所有权与用户权利

所有套餐都必须允许：

- 查看自己的结构化数据。
- 纠正错误数据。
- 导出交易记录和账户设置。
- 删除单笔交易。
- 删除账户及关联交易、截图引用、标签、映射和 AI 洞察。
- 撤回未来的 AI 图片处理同意。

“删除”必须定义：

- 产品数据库何时删除。
- 缓存何时失效。
- 备份中的数据何时自然过期。
- 第三方处理器收到删除请求的适用范围。

当前代码只有单笔交易删除和 Demo 删除；未观察到完整账户导出和级联删除的用户流程。隐私页宣称的权利尚未被产品完整证明。

## 5. 数据保存建议

阶段 0 建议，待法律复核：

- 原始 CSV：请求处理结束后不保留。
- 原始截图：默认不保留；如果未来保留，必须明确用途、期限和删除入口。
- 未确认提取候选：浏览器会话结束或 24 小时内删除。
- 正式交易记录：用户账户有效期间，由用户控制。
- 运行日志：Alpha 最长 7–30 天，并做去标识化。
- 备份：生产期采用滚动保留，并在删除政策中说明自然过期时间。

## 6. 跨境与第三方处理

收费或邀请外部用户前必须完成：

- 列出 Vercel、Turso、Google Gemini、邮件、监控和支付供应商的处理区域。
- 保存相应 DPA/条款版本和变更日期。
- 确认是否用于供应商模型训练或产品改进。
- 确认原始截图、日志和备份的保留期限。
- 明确用户请求访问、纠正、导出和删除时的责任人。

## 7. 当前高风险不一致

1. 隐私页写 DeepSeek，实际使用 Google Gemini。
2. 隐私页声称截图“stored as evidence”，但当前上传 POST 主要在内存处理；可选 screenshotUrl 存储流未说明。
3. 隐私页宣称可删除账户全部数据，但未观察到相应完整产品流程。
4. 隐私页宣称匿名使用分析，但代码审查尚未确认实际分析供应商和匿名化实现。
5. 当前登录允许任何人输入邮箱直接创建/登录，不能用于外部测试。
6. 数据库无环境变量时自动回退本地文件，生产部署必须禁止静默回退。
