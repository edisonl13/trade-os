# TRADE//OS 隐私、AI 与金融边界

状态：产品硬规则；法律文案仍需专业复核  
版本：2026-07-28

## 1. AI 调用硬规则

允许调用 AI 的唯一条件：

1. 用户主动选择或粘贴图片。
2. 用户明确点击“分析图片”。
3. 页面显示将使用的供应商、目的和是否保存原图。
4. 服务端检查套餐额度和速率限制。

禁止：

- 页面打开时调用。
- Dashboard 刷新时调用。
- 后台轮询、预取、定时任务或自动重试循环调用。
- 用户只浏览已有交易时重新调用。
- 为生成普通 KPI、图表、排序或筛选调用。
- 把 API Key 放在浏览器、日志、代码或数据库。

## 2. AI 处理范围

当前允许：

- 从用户主动上传的交易截图中提取可见字段。
- 返回结构化候选结果。
- 标明缺失字段和置信度。
- 由用户修改并确认后保存。

阶段 5 才可能允许：

- 根据服务器已计算的结构化统计，归纳可能模式。
- 组织结论、证据和复盘问题。
- 比较用户明确选择的时间段。

当前禁止：

- 从截图猜测不可见的价格、日期、盈亏或动机。
- 自动判断用户心理状态。
- 自动命名策略或强迫所有用户使用同一标签系统。
- 自动把 AI 建议加入交易规则。
- 自动生成买卖信号或未来市场方向。

## 3. 确定性、提取、推断

UI 必须明确区分：

### 确定性

- 由用户确认字段和固定公式计算。
- 可显示为正式指标。

### 提取

- 来自 Gemini/OCR。
- 保存前必须经过用户确认。
- 显示“系统识别”，不能显示成用户原始事实。

### 推断

- 来自跨交易归纳。
- 必须附组成结论的交易。
- 必须显示样本数、缺失数据和置信状态。
- 用户可以标记“不准确”。

### 不可确认

- 证据不足时明确停止。
- 不允许为了填满页面而生成结论。

## 4. 图片处理边界

默认策略：

- 图片仅用于本次字段提取。
- 原图不默认长期保存。
- 只发送完成任务所需的图片和提示。
- 用户必须先确认截图不含身份证、完整券商账号、付款信息或其他无关个人资料。
- 返回结果必须在用户确认前处于草稿状态。

如果未来需要保留图片作为交易证据：

- 与 AI 提取同意分开。
- 显示存储供应商、保留期限和删除入口。
- 允许用户不保存原图仍使用结构化交易。

## 5. AI 成本边界

每次调用记录：

- userId 的内部不可逆标识。
- 套餐。
- 模型和版本。
- 请求类型。
- 输入/输出 tokens 或供应商计费单位。
- 估算成本。
- 耗时和状态。
- 用户是否修改/拒绝结果。

禁止记录：

- API Key。
- 完整原始截图。
- 完整邮箱或券商账号。
- 未去标识的交易明细日志。

所有套餐设置硬额度。达到额度时停止并明确告知，不允许继续后台消费。

## 6. 用户控制

用户必须能够：

- 在 AI 调用前取消。
- 查看哪些字段来自 AI。
- 修改或删除 AI 提取字段。
- 拒绝一条 AI 洞察。
- 打开组成洞察的具体交易。
- 导出原始记录、修正记录和正式交易数据。
- 删除交易、图片引用、AI 洞察和账户数据。

## 7. 金融产品边界

TRADE//OS 是记录、统计和复盘工具，不是：

- 投资顾问。
- 信号服务。
- 交易执行平台。
- 跟单或资金管理服务。
- 盈利保证。

允许表达：

- “过去 30 笔中，纽约时段净结果较差。”
- “其中 12 笔交易可在这里查看。”
- “样本有限，不能证明未来表现。”
- “你可以考虑复查这些交易是否存在共同原因。”

禁止表达：

- “停止交易 EURUSD。”
- “下周应该做多。”
- “这个策略一定有效。”
- “使用该规则可将胜率提高到 60%。”
- “AI 已证明你的问题是 FOMO。”

任何改进建议都必须表达为可验证的复盘假设，不是投资建议。

## 8. 身份与访问安全

外部 Alpha 前必须：

- 移除“任意邮箱直接创建并登录”的开发预览模式。
- 使用验证邮箱、受控邀请或可靠第三方身份认证。
- 确认所有账户、交易、标签、映射和设置查询都强制 userId 隔离。
- 对敏感写入、删除、导出和 AI 调用做速率限制与审计。
- 生产环境缺少数据库或 AI 配置时安全失败，不能回退本地或错误共享状态。

## 9. 用户界面同意文本要求

图片分析入口必须简单说明：

> 只有在你点击“分析图片”后，图片才会发送给 Google Gemini 以提取可见交易字段。系统可能识别错误；保存前请检查。TRADE//OS 不会在后台自动分析。

如果不保存原图：

> 图片仅用于本次处理，TRADE//OS 默认不长期保存原图。

最终措辞必须与真实实现和供应商条款一致。
